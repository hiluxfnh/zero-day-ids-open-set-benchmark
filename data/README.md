# Datasets (not redistributed)

Datasets are large and carry their own licenses, so they are not stored in this repository.

- **NSL-KDD** (`KDDTrain+.txt`, `KDDTest+.txt`): University of New Brunswick, https://www.unb.ca/cic/datasets/nsl.html. Place in `data/nslkdd/`.
- **CICIoT2023**: Neto et al., Sensors 2023, https://www.unb.ca/cic/datasets/iotdataset-2023.html (also mirrored on Kaggle). Extract the 26 part CSVs into `data/ciciot2023/csv/`.
